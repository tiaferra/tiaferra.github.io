▶ Progetti Universitari

Android eBPF Monitor - Tesi di Laurea Triennale
github.com/tiaferra/android-ebpf-monitor

Sistema di monitoraggio e osservabilità per ambienti Android (Cuttlefish) basato su eBPF e bpftrace, con un layer di orchestrazione in Python. Permette di osservare eventi di sistema a basso livello (syscall, processi, file, rete), correlare attività tra applicazioni e generare report di sicurezza strutturati.

MAY - Progetto di Ingegneria del Software
github.com/yousef-shoeib/MAY

Applicazione di rendering 3D sviluppata in Java come progetto universitario per il corso di Ingegneria del Software (3° anno, Ingegneria Informatica, Università di Bergamo). Permette di caricare modelli 3D in formato .obj, visualizzarli in tempo reale, applicare texture e colori, navigare la scena tramite una telecamera libera e controllare posizione, rotazione e scala degli oggetti, con supporto alla gestione dell'illuminazione ambientale e diffusa.

Ricettario Web — Progetto di Programmazione Web
github.com/tiaferra/404NotFounders

Applicazione web sviluppata per il corso di Programmazione Web (3° anno). Ricettario digitale realizzato con Django, SQLite e Bootstrap 5, con importazione dati da file Excel/CSV e interfaccia responsive per la visualizzazione e ricerca delle ricette.
