Progetti Universitari

Una selezione dei progetti sviluppati durante il mio percorso di studi in Ingegneria Informatica.

Tesi di Laurea Triennale

Android eBPF Monitor

Sistema di monitoraggio e osservabilità per ambienti Android (Cuttlefish) basato su eBPF e bpftrace. Permette di osservare eventi di sistema a basso livello (syscall, processi, file, rete), correlare attività tra applicazioni e generare report di sicurezza strutturati.

github.com/tiaferra/android-ebpf-monitor

MAY

Applicazione di rendering 3D sviluppata in Java come progetto di gruppo per il corso di Ingegneria del Software. Il programma permette di caricare modelli 3D e visualizzarli in tempo reale.

github.com/yousef-shoeib/MAY
Programmazione Web

Ricettario Web

Applicazione web sviluppata in coppia per il corso di Programmazione Web. Ricettario digitale realizzato con Django, SQLite e Bootstrap 5, con importazione dati da file Excel/CSV e interfaccia responsive per la visualizzazione e ricerca delle ricette.
